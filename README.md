# ScanQC Web

스캔 이미지 검수·보정 프로그램 ScanQC의 웹 버전입니다. 설치 없이 브라우저 주소로 접속해서 씁니다.
화면과 보정 기능(자동 기울기·크롭, 회전, 크롭, 힐링·도장·지우개·브러시·펜, 선택 영역, 색 보정·곡선·색 균형, 원본 수정, 확대·축소)은 데스크톱판과 같습니다.

## 두 가지 쓰는 방법

| | 로그인 없이 · **내 PC 폴더** | 로그인 · **팀 작업** |
|---|---|---|
| 누구나 | 주소만 열면 바로 | 가입 → 관리자 승인 |
| 이미지 위치 | 내 PC 폴더를 브라우저가 직접 읽고 씀 (서버로 안 감) | Supabase 저장소 (비공개) |
| 저장 | 보정본 폴더에 바로 덮어씀 · 첫 덮어쓰기 전 백업은 이 브라우저 안에 보관 | 클라우드 보정본 · 백업도 클라우드 |
| 진행 상황 | 이 브라우저에 기억 (최근 폴더에서 다시 열기) | 어느 PC에서든 이어서 |
| 추가 기능 | — | 배정된 파일만 보기 · 같은 파일 동시 수정 방지(잠금) · 작업 기록 · 관리자 현황판 |
| 브라우저 | **PC용 Edge 또는 Chrome** | Edge 또는 Chrome 권장 |

## PC 설치형 (인터넷 없이)

검수 화면 왼쪽 **PC 설치형 받기** 버튼으로 Windows용 프로그램을 내려받을 수 있어요 (`download/ScanQC_PC.zip`).
압축을 풀고 `ScanQC.vbs` 를 더블클릭하면 바탕화면에 아이콘이 생깁니다. 폴더 전체 경로가 그대로 보이고 인터넷이 없어도 동작해요.

## 서버 없이 바로 열기 · 고치면서 보기

압축을 풀고 `index.html` 을 **Edge 또는 Chrome** 으로 열면(더블클릭 또는 창에 끌어다 놓기) 배포 없이 바로 동작합니다.
내 PC 폴더 검수·자동 보정·저장이 모두 되고, `config.js` 를 채워 두면 로그인·팀 작업도 됩니다.
화면을 고칠 때는 `index.html` 을 편집기로 고치고 브라우저에서 **F5** 로 새로 고침하면 바로 반영돼요. (관리자 페이지는 `admin.html`)

## 처음 한 번 설치 (관리자)

1. **Supabase 프로젝트 만들기** — https://supabase.com → New project. 지역(Region)은 **Northeast Asia (Seoul)** 를 고르세요.
2. **데이터베이스 만들기** — 대시보드 왼쪽 **SQL Editor** → `supabase/schema.sql` 내용을 통째로 붙여 넣고 **Run**. (다시 실행해도 안전)
3. **이메일 인증 끄기** — **Authentication → Sign In / Providers → Email** 에서 **Confirm email** 을 끄세요. 아이디로 가입하기 때문에 이게 켜져 있으면 가입이 안 됩니다.
4. **업로드 크기** — **Storage → Settings** 의 업로드 크기 제한을 스캔 파일보다 크게 (무료 요금제는 50MB까지).
5. **연결 정보 넣기** — **Project Settings → API** 의 Project URL 과 anon public 키를 `config.js` 에 넣으세요.
6. **배포** — 폴더 통째로 정적 호스팅에 올리면 끝입니다.
   - Vercel: vercel.com → Add New → Project → 이 폴더를 올리거나 Git 저장소 연결 (빌드 설정 없음). 터미널이면 이 폴더에서 `npx vercel deploy --prod`
   - 그 밖의 호스팅도 됩니다. 단 **https** 주소여야 내 PC 폴더 기능이 동작합니다 (브라우저 보안 규칙).
7. **관리자 계정** — 배포한 주소 → 왼쪽 위 **팀 작업 → 로그인·가입 → 가입 요청**. **처음 가입한 계정이 관리자**가 됩니다. 이후 가입한 사람은 관리자 페이지 **사람** 탭에서 승인하세요.

`config.js` 를 비워 두면 로그인·팀 작업·통계 없이 **내 PC 폴더** 검수만 동작합니다.

## 팀 작업 흐름

1. 관리자 페이지 (`/admin.html`) → **작업 묶음** → 새 묶음 만들기
2. **원본 폴더 올리기** (이미 올린 같은 파일은 건너뜀). 기존 보정본이 있으면 **보정본(HP) 올리기**
3. **배정** — 체크한 작업자에게 고르게 나누기, 또는 번호 범위로. 배정 안 한 파일은 승인된 누구나 볼 수 있어요
4. 작업자는 검수 화면 → 팀 작업 → 묶음 열기 → `Space` 로 확인·저장하며 진행
5. **현황판** 에서 진행률·작업자별 처리량·지금 작업 중인 파일·최근 활동 확인
6. 끝나면 **보정본 내려받기** → PC 폴더를 고르면 그 폴더에 저장

## 사용 통계 (관리자 페이지 → 사용 통계)

로그인하지 않은 사람까지 모두 기록합니다.

- 기록하는 것: 브라우저마다 만든 익명 번호, 연 폴더 이름(원본·보정본), 파일 이름, 동작(열기·보기·저장·확인·원본 복사·백업 복원), 보정 요약(회전·기울기·크롭·획 수 등), 브라우저 종류
- 기록하지 않는 것: 이미지, 폴더 전체 경로(브라우저는 폴더 이름만 알 수 있음), 개인 정보
- 화면에 "사용 통계(폴더·파일 이름, 처리 건수)만 기록돼요" 안내가 표시됩니다
- 세션을 누르면 그 사람이 연 파일과 처리 결과를 시간순으로 볼 수 있어요

## 알아 둘 점

- 창을 닫을 때 저장하지 않은 수정은 임시 저장되고, **다음에 같은 폴더(묶음)를 열면 이어서 저장**됩니다. 그 사이 다른 사람이 그 파일을 저장했다면 옛 수정으로 덮어쓰지 않습니다.
- 팀 작업에서 다른 사람이 보고 있는 파일은 "○○ 작업 중"으로 표시되고 저장되지 않습니다. 창을 닫으면 90초 뒤 잠금이 풀려요 (관리자 페이지에서 바로 풀 수도 있음).
- 저장 형식: 원본의 DPI·색상 모드·압축(LZW·G4·Deflate·PackBits·무압축)을 유지합니다. Group3 는 Group4 로, JPEG 압축 TIFF 는 LZW 로 저장합니다. JPEG 파일은 품질 100으로 저장되며 흑백 JPEG 도 3채널로 저장됩니다.
- 아주 큰 이미지(A3 컬러 600dpi 등)는 브라우저 메모리 한계로 느릴 수 있어요.
- 서울시 기록물처럼 외부 반출이 제한된 자료를 **팀 작업(클라우드)** 에 올릴 때는 발주처 보안 승인을 먼저 받으세요. **내 PC 폴더** 방식은 이미지가 PC 밖으로 나가지 않습니다.

## 파일 구성

```
index.html            검수 화면 (내 PC 폴더 · 팀 작업)
admin.html            관리자 페이지 (현황판 · 사용 통계 · 작업 묶음 · 배정 · 사람)
config.js             Supabase 연결 정보
js/codec.js           TIFF·JPEG·PNG·BMP 읽기/쓰기 (LZW·G4·Deflate·PackBits 인코더 포함)
js/analyze.js         자동 분석 (기울기·용지·내용·자동 검사) — 데스크톱판과 같은 계산, 화면과 분리된 작업 스레드에서 실행
js/engine.js          폴더/클라우드 연결 · 저장 · 잠금 · 임시 저장 · 사용 통계
vendor/               UTIF.js(MIT) · pako(MIT) · supabase-js(MIT)
supabase/schema.sql   테이블 · 권한(RLS) · 함수 · 저장소 정책
vercel.json           Vercel 캐시 설정
```

단축키 · 사용법

이렇게 쓰세요

  1. 폴더 지정 — 왼쪽 위에 원본 폴더와 보정본(HP) 폴더를 넣고 불러오기
  2. 파일 하나만 — 파일 하나만 열어 보정 (또는 이미지를 창에 끌어다 놓기) → 고친 뒤 Space 면 그 파일에 저장 · 처음 모습은 왼쪽 원본에 남아요
  3. 검수 — 오른쪽에 보정본 파일이 그대로 보여요. 이상 없으면 Space → 다음 장 · 가장자리 정리가 필요하면 F (자동 보정 스위치를 켜면 불러올 때마다 적용)
  4. 필요한 장만 고치기 — 회전 SDWA, 기울기 ,., 크롭 C, 잡티 힐링 J 등 → Space
  5. 크롭 C — 모서리·상하좌우 선을 끌거나, 아래 좌·상·우·하 칸에 px 입력 · 잡은 변은 방향키로 1px (Shift 10px) · R 확정
  6. 보정이 어려우면 Q — 원본을 그대로 보정본으로 저장
  7. 많이 넘길 때 N 자동 넘김 — 정한 초마다 확인·저장 (아래 3초 버튼으로 간격 변경, 아무 키·클릭이면 멈춤)
  8. 넓게 보기 Tab — 양쪽 패널을 숨기고 이미지만 크게

PC 설치형 ScanQC

Windows 10·11용 · 인터넷 없이 동작 · 폴더 전체 경로 표시 · 파이썬 포함(따로 설치할 것 없음)

  1. 아래 설치 파일 받기로 ScanQC_Setup.exe 내려받기 (약 20MB)
  2. 더블클릭해서 설치 → 바탕화면·시작 메뉴에 ScanQC 아이콘이 생겨요 (관리자 권한 필요 없음)
  3. 처음 한 번 'Windows의 PC 보호' 창이 뜨면 추가 정보 → 실행
  4. 지울 때는 시작 메뉴 ScanQC 제거 또는 Windows 설정 → 앱

설치 없이 쓰려면 압축 파일(zip)을 받아 풀고 ScanQC.vbs 를 실행하세요.
